# Find Second Largest Element in an Array

## Description
This Python program finds the largest and second largest elements from an array.

## Concepts Used
- Lists
- For loop
- If-elif condition
- Comparison operators
- Variables

## Example

### Input
12, 45, 7, 89, 34, 23

### Output
Largest element: 89
Second largest element: 45

## How It Works
1. The program stores numbers in a list.
2. It checks each number with the current largest value.
3. When a larger number is found, the previous largest becomes the second largest.
4. The program also checks for the next suitable value.
5. Finally, it displays the largest and second largest elements.
